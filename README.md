# سواعد الأمل  Linktree

صفحة روابط (Linktree) لنادي **سواعد الأمل** بمدرسة ENSAM الدار البيضاء.
مبنية بـ HTML / CSS / JS بسيطة — بدون أي إطار عمل أو خطوة بناء (build step)،
لتسهيل النشر على GitHub Pages، Netlify، Vercel، أو أي استضافة عادية.

## كيف تضيف الروابط

كل الروابط تُحرَّر من ملف واحد فقط: **`js/script.js`**

1. افتح `js/script.js`.
2. في أعلى الملف تجد مصفوفتين:
   - `SOCIALS` → أيقونات التواصل الصغيرة (تحت الشعار).
   - `LINKS` → القائمة الرئيسية للروابط.
3. غيّر كل `url: "#"` برابطك الحقيقي.
4. لتغيير الأيقونة، غيّر `key` إلى أحد المفاتيح الموجودة في `ICONS`
   (instagram, linkedin, whatsapp, form, calendar, link, facebook,
   tiktok, x, youtube, email, location, phone).
5. لإضافة سطر جديد في القائمة، انسخ أحد العناصر داخل `LINKS` وعدّله.
6. `gold: true` يجعل أيقونة الرابط بالذهبي بدل البني — استخدمها لرابط واحد
   تريد تمييزه (مثل رابط الانضمام).

لا حاجة لتعديل HTML أو CSS.

## البنية

```
index.html          الصفحة
css/style.css        التصميم (الألوان، الخط، شكل النجمة الزليجية)
js/script.js         الروابط + مكتبة الأيقونات + عرضها
assets/logo.svg       شعار النادي (المصدر الأصلي)
```

## الألوان المستعملة

مأخوذة من شعار النادي مباشرة:

| اسم المتغيّر | القيمة | الاستعمال |
|---|---|---|
| `--green-deep` / `--green` | `#1F3B23` → `#2F6B2E` | خلفية البطاقة العلوية |
| `--brown` / `--brown-dark` | `#4A321F` / `#2E2013` | إطار النجمة، النص |
| `--tan` | `#C9A16B` | تفاصيل الزليج |
| `--gold` | `#FFB51D` | لون العلامة الأساسي / الدعوة للفعل |
| `--cream` | `#F7F1E3` | خلفية الصفحة |
## المعاينة محليًا

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا بسيطًا:

```bash
python3 -m http.server
```
